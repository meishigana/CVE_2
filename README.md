# CVE Submission Packages

This repository stores vulnerability submission packages as separate top-level directories.

## Packages

| Package | Target | Vulnerability |
| --- | --- | --- |
| `glinet_4x_ui_update_langs_gl_timer_cron_cmdi_2026_07_07` | GL.iNet 4.x | Authenticated cron command injection via `ui.update_langs` and `gl_timer.langs.week` |
